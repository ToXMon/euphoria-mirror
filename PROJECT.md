# Kronos Condor Cup

## Project description

Kronos Condor Cup is a Condor/Hummingbot Builders Cup trading-agent project. It combines Condor's AI trading-agent harness, Hummingbot API execution, Kronos candlestick forecasting, X-monitor social signals, and geopolitical/on-chain monitor reports into an always-on autonomous agent system.

The goal is to enter the Condor Builders Cup with a competition-ready agent that can run without manual intervention for the 48-hour live event while producing clear evidence: backtests, signal journals, risk decisions, executor attribution, and session logs.

## Non-promise

This project does not promise profit. It optimizes for measured, risk-controlled decision-making, backtest evidence, uptime, and transparent agent behavior.

## Core thesis

Use Condor for orchestration and execution boundaries, Kronos as a forecasting/filter layer, X-monitor as fast narrative input, and Geo-Alpha as macro/on-chain regime context. Trade only when signal agreement and risk checks meet strict thresholds.
