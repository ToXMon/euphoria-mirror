# Skill Selection

## Always active for this project

- `planning-and-task-breakdown`: break the system into small verified workpacks.
- `prompt-engineering-harness`: write agent instructions, tool prompts, routine prompts, and judge-facing explanations.
- `swebok-quality-engineering` or `swebok-developer-knowledge`: requirements traceability, test strategy, quality gates.
- `last30days`: social signal intelligence and market narrative checks.
- `defi-scanner`: on-chain opportunity scans and RAR scoring.
- `onchain-analyzer`: contract/token safety checks before any long-tail or DeFi interaction.

## Specialist agents to use

- `researcher`: competition, market, venue, and model research.
- `architect`: system architecture and integration boundaries.
- `ai-engineer`: Kronos integration and model-serving design.
- `backend_engineer`: Condor routines, agent services, and APIs.
- `qa_engineer` / `test-engineer`: backtests, dry-run tests, failure-mode tests.
- `security-auditor`: secret handling, exchange keys, trading safety, dependency checks.
- `devops_engineer`: Docker, model cache, deployment, uptime monitoring.
- `release_manager`: submission package, README, demo, changelog.

## Human gates

Human approval required before:

- Real trading enabled.
- Exchange/API credentials added to any runtime.
- GitHub repository creation/push if public.
- Live competition deployment.
